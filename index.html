桌面顶部的待办灵动岛

Dynamic Todo Island 把最高优先级任务藏在屏幕顶部，需要时轻轻唤出。它不像一整页任务软件那样打断你，只在你抬头的时候提醒下一件真正重要的事。

不抢注意力，只托住下一步

它是一个单文件 Tkinter 桌面组件，围绕“隐藏、唤出、聚焦、完成”四个动作设计，适合常驻桌面又不想被任务管理器淹没的人。

顶部隐藏

平时只露出 10px 触发边，鼠标靠近屏幕顶部时自动展开为紧凑灵动岛。

优先级聚焦

高、中、低优先级用颜色点区分，活跃任务按优先级和创建时间自动排序。

系统托盘

托盘图标常驻，右键可以显示窗口或退出；窗口本身不会占用下方任务栏。

完成历史

完成的任务会进入历史区域，保留时间记录，也支持一键撤回误操作。

本机数据

待办保存在 %LOCALAPPDATA% 的 JSON 文件里，不需要账户、服务端或同步配置。

桌面启动

项目支持 PyInstaller 打包成 exe，并自动创建带图标的桌面快捷方式。

从一条任务到一个节奏

点击紧凑模式展开完整列表，添加新待办、选择紧急程度、滚轮查看更多任务和历史。右键拖动可以临时调整悬浮窗位置，退出则交给系统托盘。

运行方式

如果已经打包，双击桌面上的 Dynamic Todo Island 图标即可启动。开发时也可以直接运行 Python 源码。

powershell -ExecutionPolicy Bypass -File .\build_exe.ps1
.\dist\DynamicTodoIsland.exe
